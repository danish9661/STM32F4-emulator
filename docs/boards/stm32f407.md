# STM32F407 — support notes

The reference target: Discovery F407VG (1M flash, 192K RAM = 128K SRAM +
64K CCM mapped flat, 168 MHz). Every firmware suite runs here first.

## Silicon peripherals

GPIOA–I · TIM1–14 · USART1–3,6 + UART4/5 · SPI1–3 · I2C1–3 · SDIO ·
USB OTG FS + HS · CAN1/2 · DAC · ADC1–3 · DCMI · FSMC · Ethernet MAC ·
RNG · CRYP/HASH · RTC · CRC · IWDG/WWDG · EXTI · FLASH · PWR · SYSCFG ·
DBGMCU · NVIC/SysTick/SCB/MPU/FPU — all modeled.

**Absent in silicon**: DMA2D, LTDC, SAI, GPIOK, QSPI, SPI4/5/6,
UART7/8. The emulator still models some of them (harmless superset);
run those demos on [STM32F429](stm32f429.md) where they really exist.

## Board wiring (emulator rig)

- Discovery F407VG — LED **PD12**, `Serial` = **USART2** (`0x40004400`)
- Arduino `Serial` follows `uartAddr` per preset

## Feature matrix (silicon vs emulator)

One row per peripheral — no grouping. Statuses: **Full** = register-level
incl. IRQs/DMA, proven by a passing preset on this chip; **Partial** =
modeled subset (the gap is named); **Missing** = silicon has it, the model
doesn't; **Absent** = no such silicon here. Depth details:
[PERIPHERALS](../peripherals.md); Ethernet depth: [NETWORKING](../networking.md).
