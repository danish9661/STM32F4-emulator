# STM32F411 — support notes

BlackPill F411CE / Nucleo-F411RE (512K flash, 128K RAM, 100 MHz).
F401 silicon + SPI5 — and nothing else new. No CAN, no Ethernet, no
DAC/DCMI/FSMC (same absences as F401).

## Silicon peripherals

Everything on [STM32F401](stm32f401.md), plus **SPI5**. The absent list
is otherwise identical (CAN1/2, DAC, DCMI, FSMC/FMC, Ethernet MAC,
CRYP, HASH, RNG, UART4/5/7/8, USART3, TIM6/7/12/13/14, ADC2/3,
GPIOF/G/I/J/K, OTG_HS, SAI, DMA2D, LTDC, QSPI).

## Board wiring (emulator rig)

- BlackPill F411CE — LED **PC13**, `Serial` = **USART1**
- Nucleo-F411RE — LED **PA5**, `Serial` = **USART2** (`0x40004400`,
  follows `uartAddr`)

## Feature matrix (silicon vs emulator)

One row per peripheral — no grouping. F411 silicon is the F401 set plus
SPI5, so this table is the [F401 table](stm32f401.md) with the SPI5 row
added (same shared models, same gaps). Statuses: **Full** = register-level
incl. IRQs/DMA, proven by a passing preset on this chip; **Partial** =
modeled subset (the gap is named); **Absent** = no such silicon here.
Depth details: [PERIPHERALS](../peripherals.md).
