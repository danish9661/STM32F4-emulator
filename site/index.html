CPU:

Load a custom firmware: .bin (raw flash), .hex (Intel HEX), .elf (loadable segments + symbols), or a .map file for the symbol table only. Firmware files boot immediately. Nothing runs until you press Boot preset or load a file.

Network gateway

offline — using the scripted network (netsim)

When connected, all Ethernet frames are sent to a real network stack (openhw-gw + gVisor) instead of netsim. Run openhw-gw locally first. Note: GitHub Pages serves https, which blocks plain ws:// — serve this page over http:// when using a gateway.

Peripherals

Memory Watch

Live 32-bit reads each frame. Poke a hex value to write it. Reads are 32-bit aligned.

CAN injection

Boot can_host_rx (or can_demo) first, then inject a frame — the firmware receives it on its CAN RX FIFO and prints the ID + data. Standard 11-bit frames only.
