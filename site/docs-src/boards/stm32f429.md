# STM32F429 — support notes

Discovery F429ZI (2M flash, 256K RAM + 64K CCM, 180 MHz). F407 silicon
plus DMA2D, LTDC, SAI1, GPIOK, QSPI, UART7/8, SPI4/5/6 — and FMC instead
of FSMC (same controller, renamed; the model claims both names).

## Silicon peripherals

Everything on [STM32F407](stm32f407.md), plus **DMA2D, LTDC, SAI1,
GPIOK, QSPI, UART7/8, SPI4/5/6**. The model registers the FSMC window
for the FMC range and accepts the `SAI` SVD alias.

- Discovery F429ZI — LED **PG13**, `Serial` = **USART1**

## Feature matrix (silicon vs emulator)

One row per peripheral — no grouping. F429 silicon is the F407 set plus
DMA2D, LTDC, SAI, GPIOK, QSPI, UART7/8, SPI4/5/6, with FMC in place of
FSMC (same controller, renamed; the model claims both names). Statuses:
**Full** = register-level incl. IRQs/DMA, proven by a passing preset on
this chip; **Partial** = modeled subset (the gap is named); **Missing** =
silicon has it, the model doesn't. Depth details:
[PERIPHERALS](../peripherals.md); Ethernet depth: [NETWORKING](../networking.md).
